# Hyperparameter Tuning Benchmark - 20260710T051002Z

League: EPL (Understat). Walk-forward on 2018-19 to 2025-26 (8 seasons, 3040 matches per model).

**Question:** the Phase 0 report's outstanding milestone - every model has used literature-default hyperparameters, never fitted to this data. Do tuned settings beat the textbook ones? Each tuned model picks its settings by nested walk-forward search on an inner validation split of the training window only, so no setting was ever chosen by looking at the season it predicts.

## Recommendation

Best model by log loss: **ensemble** (0.9925).
Settings chosen on the final training window: elo -> k_factor=25.0, home_advantage=120.0; dixon_coles_xg -> xi=0.002.

Default vs tuned, same model, identical matches:
- **elo**: 0.9956 -> tuned 0.9963 — **tuning does NOT help** (not significant: t p=0.5654, Wilcoxon p=0.0083).
- **dixon_coles_xg**: 1.0107 -> tuned 1.0151 — **tuning does NOT help** (not significant: t p=0.1297, Wilcoxon p=0.0237).
- **ensemble**: 0.9925 -> tuned 0.9943 — **tuning does NOT help** (not significant: t p=0.1225, Wilcoxon p=0.0165).

The tuned ensemble (0.9943) does not beat the default one (0.9925). The literature defaults were already near-optimal for this data - a genuinely useful null result: it closes the outstanding Phase 0 milestone and rules tuning out as a lever.
